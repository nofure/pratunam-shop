# ระบบร้าน — ขายหน้าร้าน ปิดยอด สต็อก รายงาน

เปิดใช้งาน: **https://nofure.github.io/pratunam-shop/**

ระบบสำหรับร้านเสื้อผ้า-รองเท้าในตลาดที่ตั้งราคาเป็นราว/กระบะ (39, 59, 100, 299 …)
ขายด้วยการแตะ "ปุ่มราคา" แทนการยิงบาร์โค้ด ใช้บนมือถือหรือแท็บเล็ตได้ และขายได้แม้เน็ตหลุด

- ขาย: แตะปุ่มราคา คิดโปร "3 ตัว 100" ให้เอง ลดราคาตอนลูกค้าต่อ รับเงินสด (คิดเงินทอน) / QR พร้อมเพย์ที่ใส่ยอดให้แล้ว / คนละครึ่ง
- เปิดร้าน–ปิดยอด: ใส่เงินทอนตอนเช้า จดเงินเข้า-ออกลิ้นชัก ตอนเย็นนับเงิน ระบบบอกว่าขาดหรือเกินกี่บาท แล้วส่งสรุปเข้า LINE
- บิล: ดูบิลย้อนหลัง ยกเลิกบิลต้องใช้ PIN เจ้าของ (บิลที่ยกเลิกยังเห็นในรายงาน)
- สต็อก: รับของเข้าพร้อมทุน นับสต็อก ปรับสต็อก ย้ายของระหว่างแผง ร้านที่ไปซื้อของ
- ค่าใช้จ่าย: ค่าแผง ค่าไฟ ค่าจ้าง ถุง และเงินที่หยิบจากลิ้นชัก
- รายงาน (เฉพาะเจ้าของ): ยอดขาย กำไร ปุ่มราคาขายดี คนขาย เงินขาด-เกิน ช่วงเวลาขายดี ของใกล้หมด ของค้างสต็อก ดาวน์โหลด Excel (CSV)

## ติดตั้งบนมือถือ / แท็บเล็ต (ทำครั้งเดียวต่อเครื่อง)

**Android (Chrome)**
1. เปิด https://nofure.github.io/pratunam-shop/ ด้วย Chrome
2. กดปุ่ม ⋮ มุมขวาบน → **ติดตั้งแอป** (หรือ **เพิ่มลงในหน้าจอหลัก**)
3. จะมีไอคอน ฿ สีเหลืองบนหน้าจอ ต่อไปเปิดจากไอคอนนี้

**iPhone / iPad (Safari)**
1. เปิดลิงก์ด้วย Safari
2. กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น) → **เพิ่มไปยังหน้าจอโฮม**

หลังเปิดครั้งแรกแล้ว แอปใช้ได้แม้ไม่มีเน็ต

## เริ่มใช้งานครั้งแรก (เจ้าของร้าน · ประมาณ 3 นาที)

1. เปิดแอป เลือก **เริ่มตั้งค่าร้านใหม่**
2. ใส่ชื่อร้าน → ชื่อเจ้าของและ PIN 4 หลัก (จำไว้ให้ดี ใช้ดูรายงานและอนุมัติยกเลิกบิล)
3. เลือก **ใช้ปุ่มราคาตามป้ายในร้าน** (3 แผง 18 ปุ่ม ตามป้ายราคาในรูปร้าน แก้ทีหลังได้) หรือ **ตั้งเอง**
4. ใส่เบอร์พร้อมเพย์ของร้าน (ไม่ใส่ก็ได้) และเลือกว่ารับคนละครึ่งไหม
5. เลือกว่าเครื่องนี้ขายที่แผงไหน

จากนั้นไปที่ **เมนู → ตั้งค่า**
- **ปุ่มราคา**: แก้ชื่อ ราคา โปร สี ให้ตรงกับป้ายจริงในร้าน
- **คนขาย**: เพิ่มชื่อคนขายแต่ละคนพร้อม PIN ของตัวเอง

### อยากให้คนขายลองก่อน
**เมนู → ตั้งค่า → ข้อมูล → สร้างข้อมูลทดลอง 14 วัน** แล้วลองขาย ลองปิดยอด ลองดูรายงานได้เต็มที่
พร้อมใช้จริงเมื่อไหร่ กด **เริ่มใช้งานจริง: ล้างข้อมูลการขาย** (การตั้งค่าร้าน ปุ่มราคา และคนขายยังอยู่)

## ใช้งานทุกวัน (คนขาย)

1. **เช้า:** แตะชื่อตัวเอง ใส่ PIN → แท็บ **ปิดยอด** → **เปิดร้าน** (ใส่เงินทอนที่มีในลิ้นชัก)
2. **ขาย:** แท็บ **ขาย** แตะปุ่มราคาตามป้ายของที่ลูกค้าหยิบ → **รับเงิน** → เลือก เงินสด / โอน-QR / คนละครึ่ง
   - ลูกค้าต่อราคา: ในตะกร้ากด **ลด / ต่อราคา**
   - ของที่ไม่มีปุ่ม: กด **ราคาอื่น** แล้วพิมพ์ราคา
   - QR: ให้ลูกค้าสแกนจากจอ ยอดใส่ไว้ให้แล้ว ดูแจ้งเตือนเงินเข้าก่อนกด **เงินเข้าแล้ว**
3. **หยิบเงินจากลิ้นชัก** (ค่าข้าว ซื้อถุง เจ้าของมาเก็บเงิน): แท็บ **ปิดยอด** → **เงินออก** ทุกครั้ง ไม่งั้นเงินจะขาด
4. **เย็น:** แท็บ **ปิดยอด** → **ปิดยอด** → นับเงินทีละแบงก์ → ดูว่าตรง/ขาด/เกิน → เช็กยอดโอนกับแอปธนาคาร
   และยอดคนละครึ่งกับแอปถุงเงิน → **ปิดยอด** → กด **ส่งเข้า LINE** ส่งให้เจ้าของ

**กติกาสำคัญ:** กดบิลก่อนรับเงินทุกครั้ง · เริ่มวันด้วยเงินทอนเท่ากันทุกวัน · เปลี่ยนคนขายให้กดรูปกุญแจมุมขวาบน

## สำหรับเจ้าของร้าน

- **รายงาน:** แท็บ **รายงาน** เลือกวันนี้ / 7 วัน / เดือนนี้ และเลือกแผงได้
- **รับของเข้า:** เมนู → **รับของเข้า** ใส่จำนวน (ใส่เป็นโหลได้) และทุน → รายงานจะคิดกำไรให้ และรู้ว่าของเหลือเท่าไหร่
- **นับสต็อก:** เดือนละครั้ง ตอนร้านปิด นับตามราว/กระบะ แล้วใส่จำนวนจริง
- **ค่าใช้จ่าย:** เมนู → **ค่าใช้จ่าย** (ค่าแผง ค่าไฟ ค่าจ้าง) มีปุ่มคัดลอกจากเดือนก่อน
- **ประวัติการปิดยอด:** เมนู → ดูยอดและเงินขาด-เกินย้อนหลังทุกวัน

### ⚠️ ข้อมูลอยู่ในเครื่อง — สำรองไว้เสมอ
ข้อมูลการขายเก็บอยู่ในมือถือ/แท็บเล็ตแต่ละเครื่อง (ไม่ได้อยู่บนเว็บ) ถ้าเครื่องหายหรือล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหาย
- ใช้เครื่องเดียว: **เมนู → ตั้งค่า → ข้อมูล → ดาวน์โหลดไฟล์สำรอง** ทุกสัปดาห์ แล้วเก็บไฟล์ไว้ใน Google Drive / LINE Keep
- ใช้หลายเครื่อง หรืออยากให้สรุปยอดเด้งเข้า LINE เอง: ตั้งค่า **ซิงก์กับ Google Sheet** ตาม
  [คู่มือตั้งค่าซิงก์และ LINE](docs/sync-setup.md) (ฟรี ทำครั้งเดียว ~20 นาที ข้อมูลทุกเครื่องจะเก็บใน Google Sheet ของเจ้าของร้าน)

## สำหรับนักพัฒนา

```bash
npm install
npm run dev        # เปิดที่ http://localhost:5173
npm test           # ทดสอบ (vitest)
npm run build      # สร้างไฟล์เว็บใน dist/
```

- React 19 + TypeScript + Vite, เก็บข้อมูลด้วย IndexedDB (Dexie), เป็น PWA ใช้ออฟไลน์ได้
- push ขึ้น branch `main` แล้ว GitHub Actions จะทดสอบและ deploy ขึ้น GitHub Pages ให้อัตโนมัติ
- โครงสร้างและกติกาของโค้ดอยู่ใน [SPEC.md](SPEC.md) · ตัวเชื่อม Google Sheet อยู่ที่ [backend/Code.gs](backend/Code.gs)

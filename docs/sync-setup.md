# ตั้งค่าซิงก์หลายเครื่อง และส่งสรุปเข้า LINE

คู่มือนี้สำหรับเจ้าของร้าน ทำครั้งเดียวประมาณ 15–20 นาที ใช้คอมพิวเตอร์จะง่ายที่สุด

> **ไม่ทำก็ใช้ได้** แอปทำงานในเครื่องเดียวได้ครบทุกอย่างโดยไม่ต้องตั้งค่านี้
> และยังส่งสรุปยอดเข้า LINE ได้ด้วยปุ่ม **แชร์ LINE** (กดแล้วเลือกแชทที่จะส่งเอง)
> ทำตามคู่มือนี้เมื่ออยากให้ **หลายเครื่องเห็นข้อมูลเดียวกัน** หรืออยากให้ **สรุปยอดเด้งเข้า LINE เอง**

## ซิงก์ทำอะไร

- ทุกเครื่องเก็บข้อมูลไว้ในเครื่องตัวเอง ขายได้แม้ไม่มีเน็ต
- เมื่อมีเน็ต แอปจะส่งข้อมูลขึ้น Google Sheet ของเจ้าของร้าน และดึงข้อมูลจากเครื่องอื่นลงมา
  (ทุก 1 นาที และหลังขายเสร็จไม่กี่วินาที)
- Google Sheet เป็นของเจ้าของร้านเอง ฟรี ไม่มีใครอื่นเห็น
- มุมขวาบนของแอปจะบอกสถานะ: **ซิงก์แล้ว** / **รอส่ง 3** / **ออฟไลน์** / **ซิงก์ไม่สำเร็จ** (กดที่ป้ายเพื่อซิงก์ทันที)
- ถ้าสองเครื่องแก้ข้อมูลเดียวกัน (เช่น ชื่อแผง ราคา) **อันที่แก้ทีหลังจะชนะ**
  จึงควรตั้งเวลาในทุกเครื่องเป็น "อัตโนมัติ"

## ส่วนที่ 1 — สร้าง Google Sheet และตัวเชื่อม

### 1. สร้าง Google Sheet

1. เข้า <https://sheets.google.com> ด้วยบัญชี Google ของเจ้าของร้าน
2. กด **ว่างเปล่า (Blank)** เพื่อสร้างชีตใหม่
3. ตั้งชื่อชีตมุมซ้ายบน เช่น `ข้อมูลร้าน`

### 2. เปิด Apps Script แล้ววางโค้ด

1. ในชีตนั้น กดเมนู **ส่วนขยาย (Extensions) > Apps Script**
2. จะเปิดหน้าใหม่ มีไฟล์ชื่อ `Code.gs` ที่มีโค้ดตัวอย่างอยู่
3. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดทั้งหมดจากไฟล์ `backend/Code.gs` ของระบบนี้แทน
4. กดรูปแผ่นดิสก์ **บันทึก (Save)**
5. ตั้งชื่อโปรเจ็กต์มุมซ้ายบน เช่น `ตัวเชื่อมร้าน`

### 3. ตั้งรหัสซิงก์ (SYNC_KEY)

รหัสซิงก์คือรหัสลับที่ทุกเครื่องต้องใส่ให้ตรงกัน เหมือนรหัสผ่านของร้าน

1. ในหน้า Apps Script กดรูปเฟือง **การตั้งค่าโปรเจ็กต์ (Project Settings)** ที่แถบซ้าย
2. เลื่อนลงไปที่ **พร็อพเพอร์ตี้ของสคริปต์ (Script Properties)** > **เพิ่มพร็อพเพอร์ตี้ของสคริปต์ (Add script property)**
3. ช่อง **พร็อพเพอร์ตี้ (Property)** พิมพ์ `SYNC_KEY`
4. ช่อง **ค่า (Value)** พิมพ์ข้อความยาวๆ ที่เดายาก อย่างน้อย 16 ตัว เช่น `แผงเสื้อ-ประตูน้ำ-7k3m-x9pq-2569`
   (ห้ามใช้เบอร์โทรหรือวันเกิด)
5. กด **บันทึกพร็อพเพอร์ตี้ของสคริปต์ (Save script properties)**

> ข้ามข้อนี้ก็ได้ ขั้นต่อไป `setup` จะสร้างรหัสให้เอง และแสดงใน **บันทึกการดำเนินการ (Execution log)**
> ดูหรือแก้รหัสได้ทีหลังที่ **การตั้งค่าโปรเจ็กต์ > พร็อพเพอร์ตี้ของสคริปต์**

### 4. เรียกใช้ setup ครั้งเดียว และอนุญาตสิทธิ์

1. กลับไปที่ไอคอน **ตัวแก้ไข (Editor)** `< >` แถบซ้าย
2. แถบด้านบน ช่องเลือกฟังก์ชัน เลือก **setup** แล้วกด **เรียกใช้ (Run)**
3. จะมีหน้าต่าง **ต้องมีการให้สิทธิ์ (Authorization required)** กด **ตรวจสอบสิทธิ์ (Review permissions)** แล้วเลือกบัญชีของเจ้าของร้าน
4. ถ้าเห็น **Google ไม่ได้ยืนยันแอปนี้ (Google hasn't verified this app)** ไม่ต้องตกใจ เพราะเป็นแอปที่เราสร้างเอง
   กด **ขั้นสูง (Advanced)** > **ไปที่ ตัวเชื่อมร้าน (ไม่ปลอดภัย) (Go to … (unsafe))**
5. กด **อนุญาต (Allow)**
6. รอจนด้านล่างขึ้นว่า **ตั้งค่าเสร็จแล้ว** และจดรหัสซิงก์ที่แสดงไว้
7. กลับไปดู Google Sheet จะมีแท็บใหม่ 11 แท็บ: `shop`, `booths`, `staff`, `tiers`, `suppliers`, `shifts`, `sales`, `cashMoves`, `lots`, `adjustments`, `expenses`

### 5. ทำให้ใช้งานได้เป็นเว็บแอป (Deploy)

1. มุมขวาบน กด **การทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดรูปเฟืองข้างคำว่า **เลือกประเภท (Select type)** > เลือก **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้
   - **คำอธิบาย (Description)**: `ตัวเชื่อมร้าน`
   - **เรียกใช้ในฐานะ (Execute as)**: **ฉัน (Me)**
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access)**: **ทุกคน (Anyone)**
4. กด **ทำให้ใช้งานได้ (Deploy)** (ถ้าถามสิทธิ์อีก ให้อนุญาตเหมือนข้อ 4)
5. คัดลอก **URL ของเว็บแอป (Web app URL)** ที่ **ลงท้ายด้วย `/exec`** เก็บไว้
   ส่งให้ตัวเองทาง LINE ก็ได้ จะได้เปิดคัดลอกในมือถือ

> "ทุกคน" หมายถึงเครื่องที่มีลิงก์นี้ส่งข้อมูลเข้ามาได้ แต่ **ต้องมีรหัสซิงก์ที่ถูกต้อง** ถึงจะอ่านหรือเขียนข้อมูลได้
> เปิดลิงก์นี้ในเบราว์เซอร์จะเห็นหน้า "ตัวเชื่อมข้อมูลร้านทำงานอยู่" ซึ่งไม่แสดงข้อมูลร้าน

### 6. ใส่ลิงก์และรหัสในแอป (เครื่องแรก)

ใช้เครื่องที่ตั้งค่าร้านไว้แล้วและมีข้อมูลอยู่

1. เข้าแอปด้วย PIN เจ้าของ
2. ไปที่ **เมนู > ตั้งค่า > ซิงก์และ LINE**
3. วาง **ลิงก์ Apps Script** (ที่ลงท้ายด้วย `/exec`) และพิมพ์ **รหัสซิงก์**
4. กด **ทดสอบการเชื่อมต่อ** รอจนขึ้นว่า **เชื่อมต่อสำเร็จ** แล้วกด **บันทึก**
5. รอสักครู่ ป้ายมุมขวาบนจะเปลี่ยนเป็น **ซิงก์แล้ว** และข้อมูลจะขึ้นใน Google Sheet

### 7. เพิ่มเครื่องที่สอง สาม …

ใช้กับ **เครื่องใหม่ที่ยังไม่ได้ตั้งค่าร้าน**

1. ที่เครื่องแรก ไปที่ **เมนู > ตั้งค่า > ซิงก์และ LINE** แล้วกด **ส่งลิงก์และรหัสไปเครื่องใหม่**
   (เช่น ส่งเข้า LINE ของตัวเอง แล้วเปิดข้อความนั้นในเครื่องใหม่)
2. เปิดแอปในเครื่องใหม่ จะเจอหน้าตั้งค่าร้านครั้งแรก เลือก **เชื่อมกับร้านที่มีอยู่**
3. คัดลอกข้อความที่ส่งมา **ทั้งข้อความ** แล้ววางในช่องลิงก์ ลิงก์และรหัสจะใส่ให้เอง
   (หรือวางลิงก์ `/exec` และพิมพ์รหัสซิงก์เองก็ได้) แล้วกด **เชื่อมต่อ**
4. รอให้ดึงข้อมูลร้านลงมา (ร้านที่มีข้อมูลเยอะอาจใช้เวลา 1–2 นาที) แล้วเข้าสู่ระบบด้วย PIN เดิม
5. เลือกแผงของเครื่องนี้

> **อย่า** กด "ตั้งค่าร้านใหม่" ในเครื่องที่สองก่อนเชื่อม เพราะจะได้แผงและราคาชุดใหม่ปนเข้าไปในร้าน
> ถ้าเผลอตั้งไปแล้ว ให้ไปที่ เมนู > ตั้งค่า > ข้อมูล > ล้างเครื่องนี้ทั้งหมด ก่อน แล้วค่อยเลือก "เชื่อมกับร้านที่มีอยู่"

## ส่วนที่ 2 — ส่งสรุปยอดเข้า LINE อัตโนมัติ (ไม่บังคับ)

ใช้ LINE Official Account (บัญชีร้านค้าใน LINE) ส่งข้อความหาเจ้าของร้าน เช่น สรุปตอนปิดยอดแต่ละแผง

### 1. สร้าง LINE Official Account

1. เข้า <https://manager.line.biz> แล้วเข้าสู่ระบบด้วย LINE ของเจ้าของร้าน
2. กด **สร้างบัญชี** ใส่ชื่อบัญชี เช่น `แจ้งยอดร้าน` เลือกหมวดหมู่ให้ตรงร้าน
3. แพ็กเกจเริ่มต้นเป็นแบบฟรี ใช้ได้เลย
   (แพ็กเกจฟรีมี **จำนวนข้อความต่อเดือนจำกัด** ถ้าส่งครบ แอปจะแจ้งว่าครบโควตา ส่วนปุ่มแชร์ LINE ยังใช้ได้ตามปกติ)

### 2. เปิดใช้ Messaging API

1. ใน LINE Official Account Manager เลือกบัญชีที่สร้าง > **ตั้งค่า (Settings)** > **Messaging API**
2. กด **ใช้ Messaging API (Enable Messaging API)** แล้วสร้างหรือเลือก **ผู้ให้บริการ (Provider)** เช่นชื่อร้าน
3. ระบบจะสร้าง **ช่อง (Channel)** ให้ใน LINE Developers

### 3. เอา Channel access token (LINE_TOKEN)

1. เข้า <https://developers.line.biz/console/> เลือก Provider > ช่องของบัญชีร้าน
2. ไปที่แท็บ **Messaging API**
3. เลื่อนลงล่างสุด หัวข้อ **Channel access token (long-lived)** กด **Issue**
4. คัดลอกข้อความยาวๆ ที่ได้ นี่คือ `LINE_TOKEN` (เก็บเป็นความลับ)

### 4. เอา User ID ของเจ้าของร้าน (LINE_TO)

1. ในช่องเดียวกัน ไปที่แท็บ **Basic settings**
2. เลื่อนลงหา **Your user ID** จะขึ้นต้นด้วยตัว `U` ยาว 33 ตัว
3. คัดลอกไว้ นี่คือ `LINE_TO`

### 5. เพิ่มบัญชีร้านเป็นเพื่อน

1. ในแท็บ **Messaging API** จะมี **QR code** ของบัญชี
2. เปิด LINE ในมือถือของเจ้าของร้าน สแกน QR แล้วกด **เพิ่มเพื่อน**
   (ถ้าไม่ได้เป็นเพื่อนกัน จะส่งข้อความไม่ถึง)

### 6. ใส่ค่าใน Apps Script

1. กลับไปหน้า Apps Script > **การตั้งค่าโปรเจ็กต์ > พร็อพเพอร์ตี้ของสคริปต์**
2. เพิ่ม 2 ค่า
   - `LINE_TOKEN` = Channel access token จากข้อ 3
   - `LINE_TO` = User ID จากข้อ 4
3. กด **บันทึกพร็อพเพอร์ตี้ของสคริปต์**
4. ทดสอบ: ไปที่ **ตัวแก้ไข** เลือกฟังก์ชัน **testLine** แล้วกด **เรียกใช้**
   ถ้าตั้งถูก LINE ของเจ้าของร้านจะได้ข้อความ "ทดสอบส่ง LINE จากระบบร้าน"

ไม่ต้องทำให้ใช้งานได้ใหม่หลังแก้พร็อพเพอร์ตี้ ค่าใหม่มีผลทันที

### 7. เปิดการส่งในแอป

ที่ **เมนู > ตั้งค่า > ซิงก์และ LINE** เปิด **ส่งสรุปเข้า LINE อัตโนมัติตอนปิดยอด** (ตั้งแยกทีละเครื่อง)
แล้วกด **ทดสอบส่ง LINE** เพื่อดูว่าข้อความเข้า LINE ของเจ้าของร้าน
ถ้าตอนปิดยอดไม่มีเน็ต แอปจะเก็บข้อความไว้และส่งให้เองเมื่อกลับมาออนไลน์ (ไม่ส่งซ้ำ)

## ข้อควรรู้

- **เก็บลิงก์และรหัสซิงก์เป็นความลับ** ใครมีทั้งสองอย่างจะอ่านข้อมูลร้านได้ทั้งหมด รวมถึง PIN ของพนักงาน
  ถ้าคิดว่ารหัสรั่ว ให้เปลี่ยน `SYNC_KEY` ใน Apps Script แล้วใส่รหัสใหม่ในทุกเครื่อง
- **อย่าแชร์ Google Sheet ให้คนอื่นแก้ไข** และอย่าแก้ ลบ หรือเรียงลำดับแถวในแท็บข้อมูลทั้ง 11 แท็บ
  อยากดูแบบกรองให้ใช้ **ข้อมูล > มุมมองตัวกรอง (Data > Filter views)** หรือสร้างแท็บใหม่ของตัวเองไว้สรุปยอดด้วยสูตร
- ข้อมูลที่ลบในแอปจะยังอยู่ในชีต โดยคอลัมน์ `deleted` เป็น `1` (เพื่อให้ทุกเครื่องรู้ว่าถูกลบ)
- **แก้โค้ด Code.gs ภายหลัง** (เช่น ได้รุ่นใหม่): วางโค้ดใหม่ > บันทึก > **การทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ (Manage deployments)**
  > กดรูปดินสอ > **เวอร์ชัน (Version): เวอร์ชันใหม่ (New version)** > **ทำให้ใช้งานได้**
  วิธีนี้ลิงก์ `/exec` จะเหมือนเดิม (ถ้ากด "การทำให้ใช้งานได้รายการใหม่" จะได้ลิงก์ใหม่ ต้องไปแก้ทุกเครื่อง)
- เปลี่ยนไปใช้ชีตใหม่: ใส่ลิงก์ใหม่ในแอป แอปจะส่งข้อมูลทั้งหมดในเครื่องขึ้นชีตใหม่ให้เอง
- บัญชี Google ฟรีมีโควตาการใช้งานต่อวัน ร้านขนาดเล็กถึงกลางใช้ไม่ถึง

## แก้ปัญหา

| แอปขึ้นว่า | ทำอย่างไร |
|---|---|
| รหัสไม่ถูกต้อง | รหัสในแอปไม่ตรงกับ `SYNC_KEY` ใน Apps Script ตรวจตัวพิมพ์เล็ก-ใหญ่และช่องว่าง |
| ยังไม่ได้ตั้ง SYNC_KEY ใน Apps Script | ทำขั้นที่ 3 หรือเรียกใช้ `setup` อีกครั้ง |
| ลิงก์ไม่ถูกต้อง ใช้ลิงก์ /exec และตั้งให้ "ทุกคน" เข้าถึงได้ | ใช้ลิงก์ที่ลงท้าย `/exec` และตรวจว่า "ผู้ที่มีสิทธิ์เข้าถึง" เป็น **ทุกคน** |
| ไม่พบลิงก์นี้ ตรวจลิงก์อีกครั้ง | ลิงก์ผิดหรือถูกลบการทำให้ใช้งานได้ไปแล้ว คัดลอกลิงก์ใหม่จาก "จัดการการทำให้ใช้งานได้" |
| เชื่อมต่อไม่ได้ ตรวจลิงก์และอินเทอร์เน็ต / ออฟไลน์ | ไม่มีเน็ต ขายต่อได้ตามปกติ ข้อมูลอยู่ในเครื่อง จะซิงก์เองเมื่อมีเน็ต |
| โค้ด Apps Script ไม่ตรงรุ่น | วาง `Code.gs` รุ่นล่าสุด แล้วทำให้ใช้งานได้เป็นเวอร์ชันใหม่ |
| เวลาในเครื่องไม่ตรง | ตั้งวันเวลาในมือถือ/แท็บเล็ตเป็นอัตโนมัติ |
| รอส่ง (ตัวเลข) ค้างนาน | ตรวจเน็ต แล้วกดที่ป้ายมุมขวาบนเพื่อซิงก์ทันที |
| ยังไม่ได้ตั้งค่า LINE ใน Apps Script | ทำส่วนที่ 2 ข้อ 6 |
| LINE_TOKEN ไม่ถูกต้องหรือหมดอายุ | ออก Channel access token ใหม่ แล้วแก้ `LINE_TOKEN` |
| ส่ง LINE ไม่สำเร็จ ตรวจ LINE_TO และเพิ่ม LINE OA เป็นเพื่อนก่อน | ตรวจ `LINE_TO` (ขึ้นต้นด้วย U) และสแกน QR เพิ่มเพื่อน |
| ส่ง LINE ครบโควตาของเดือนนี้แล้ว | รอเดือนใหม่ หรือใช้ปุ่มแชร์ LINE ไปก่อน |
